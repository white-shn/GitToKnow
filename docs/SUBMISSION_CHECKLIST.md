# Submission Checklist

**Deadline: 5:00 PM IST, Sunday 25 October 2026.** A project that isn't submitted in OrganizerHQ can't be judged or win. Aim to submit by **4:30 PM** and stop adding features by **4:00 PM**.

One team member submits for everyone.

## 1. Eligibility (all must be true)

- [ ] Every member is a registered, checked-in student aged 18+
- [ ] Public GitHub repository with an open-source license (MIT `LICENSE` is in the repo; make sure the repo is public)
- [ ] Open-source / open-weight AI is an important part of how it works
- [ ] README names each model and links its license or terms
- [ ] AI tools used are credited (see the log below)
- [ ] Submitted in OrganizerHQ before 5:00 PM with **both challenges ticked**
- [ ] Gemma 4 is called through the Gemini API (Best Use of Gemma 4)

## 2. Root `README.md` must contain

- [ ] What the project does and how it works
- [ ] Team members
- [x] License (`LICENSE` file, MIT)
- [ ] Each open-source / open-weight model used, with a link to its license or terms
- [ ] Libraries, frameworks, APIs and datasets used
- [ ] AI coding tools used, and which parts they produced
- [ ] How to run it
- [ ] Gemma 4: the exact model used, and how the project calls it through the Gemini API

## 3. OrganizerHQ submission steps

1. Sign in with the account used to register.
2. On the event page, select **Challenges** in the "View and submit challenges for this event" banner.
3. Select **Add Submission** (only visible while submissions are open).
4. Enter the public GitHub repo link, project name, description, and technologies used.
5. Add a demo URL (optional).
6. Under **Which challenge(s) are you submitting to?**, tick every challenge we're eligible for.
7. Select **Submit Project** before the deadline.

## 4. Demo prep (5 min + 3 min Q&A)

- [ ] The app runs end to end on the demo machine (server + client), with a repo already tested
- [ ] Pick a demo repo that works reliably and have a backup
- [ ] Show the working product, not slides
- [ ] Every member can explain their own part and any file a judge opens
- [ ] Be ready to say what the open-source AI does and where Gemma 4 is called in the code
